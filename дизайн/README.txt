ALARM — материалы по дизайну
=============================

Прототип брутального редизайна будильника-челленджера, сведённый с текущим кодом приложения.

СОДЕРЖИМОЕ
----------
Alarm-прототип-дизайна.html   Готовый прототип, один файл. Открывается двойным
                              кликом в любом браузере, работает офлайн. Кликабельно:
                              меню -> испытания -> экраны тревоги -> победа, шторки настроек.

исходник/                     Редактируемый исходник прототипа:
  Alarm - Brutal Redesign.dc.html
  support.js                  (должен лежать рядом с .dc.html)

app-icon/                     Иконка приложения для Android (адаптивная):
  drawable/                   векторные слои (фон + будильник)
  mipmap-anydpi-v26/          ic_launcher.xml
  values/colors.xml           цвета иконки
  README.txt                  куда класть в проекте

ДИЗАЙН-ЯЗЫК
-----------
Сигнальный красный #FF0026    экраны тревоги (примеры / реакция / отжимания)
Белый                         NFC-тревога и экран победы
Акцент #C24A32                оранжевые иконки и переключатели в меню/шторках
Шрифт                         Archivo (аналог Black-начертания в приложении)

Структура: две полные страницы (меню, список испытаний), всё остальное — шторки снизу.
