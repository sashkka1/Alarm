## 🎙 Запись ночи по звуку — что выяснилось при реализации (2026-08-26)

Приложение умеет писать ночь целиком в файл. Это **заготовка под будущую замену Sleep Cycle**: владелец хочет разбирать сон по звуку сам, и для этого нужны настоящие ночи. Подробности и порядок проверки — в `docs/karta-rabot/zapis-nochi.md`, здесь только то, без чего непонятен код.

- ⚠️ **Микрофон включается ТОЛЬКО кнопкой.** Ни расписания, ни автозапуска по вечерам нет и не появляется без прямой просьбы владельца («автоматически некорректно, просто на главный добавить кнопку», 2026-08-26).
- 🔴 **`START_NOT_STICKY` у службы записи — не мелочь, а защита от двух бед сразу.** С `START_STICKY` система подняла службу через 280 мс после остановки, с пустым намерением, то есть по ветке «начать заново»: микрофон включился **сам** и затёр 17 записанных секунд. Поймано на телефоне 2026-08-26. Пережить смерть процесса запись всё равно не может — микрофон закрывается вместе с ним.
- 🔴 **Записанное не затирается никогда.** Имя файла точно до минуты, и два запуска подряд открывали один файл. Занятое имя получает номер (`NightRecorder.freeName`). Ночь стоит восьми часов сна.
- ⚠️ **Заголовок WAV переписывается по ходу записи**, раз в минуту, а не только в конце: в нём дважды записан размер, и файл, оборванный выключением телефона, иначе остался бы непроигрываемым целиком. Есть и починка задним числом — `NightRecorder.repair`.
- ⚠️ **Служба переднего плана с типом `microphone` — единственный способ писать при погашенном экране.** С Android 14 без `FOREGROUND_SERVICE_MICROPHONE` она не стартует вовсе, а фоновое приложение получает **ровную тишину вместо звука** — и узнать об этом можно только наутро по пустому файлу.
- ⚠️ **Отказ в разрешении на микрофон выглядит как исправная запись:** `AudioRecord` создаётся, `startRecording` не бросает, в файл идёт тишина. Поэтому `MICROPHONE` есть в списке разрешений на экране (P0 №8), а кнопка сама спрашивает его и начинает запись прямо из ответа на диалог.
- ⚠️ **`NightRecordTestReceiver` открыт наружу, но закрыт разрешением `android.permission.DUMP`** — оно есть у оболочки adb и нет у обычных приложений. Без него проверить запись нечем: кнопка нажимается только пальцем, а `adb shell input` Xiaomi не отдаёт. Открывать запуск микрофона кому попало нельзя ни ради какого удобства.
- **Останавливает запись первое из трёх:** зазвонил будильник (`FOREIGN_RING` от Sleep Cycle или стандартных часов — с 2026-09-30, либо подъём нашей тревоги), настало девять утра, нажата кнопка. Путей от звонка два независимых — уведомление и звук, — потому что слушатель уведомлений однажды уже молчал после чистой установки (2026-08-19).
- ✅ **Проверено на телефоне 2026-08-26:** тишина в комнате даёт уровень 3–8, голос 584–1107, пик 6504 из 32767 — звук настоящий, тихое не прибито в ноль, громкое не срезано. Остановка по звонку — через 483 мс.
- ✅ **Проверено на телефоне 2026-08-27:** настоящая ночь (23:59:27→07:00:01, семь часов, расхождение звука со стенными часами 0,5 с); остановка по звонку Sleep Cycle (`foreign.ring` → запись встала за 258 мс); крайний срок вживую — `LIMIT_HOUR` временно передвинут на вечер, запись встала сама с опозданием 0,56 с и правило возвращено на 9:00 в том же заходе.
- ⚠️ **Установка APK обрывает идущую запись:** процесс перезапускается и уносит микрофон с собой. Файл уцелеет, но события об остановке в журнале не будет. Пока пишется ночь — не ставить.
- ⚠️ **Ночь весит около 900 МБ**, и передачи по сети для неё нет намеренно: журнал ходит строками, гигабайт по нему не пройдёт. Записи забираются кабелем.
