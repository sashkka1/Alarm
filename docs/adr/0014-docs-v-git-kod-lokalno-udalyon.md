# ADR-0014 — Документы будильника идут в git, локальная копия кода удаляется

**Дата:** 2026-10-14 · **Статус:** принято · **Меняет:** правило 2026-08-29 «документы работы в git не идут» — только для `docs/` этого репозитория

## Решение
- Проект завершён (владелец: «мы в какой-то степени его доделали, он больше не нужен; я им просто пользуюсь»).
- `docs/` (ADR, факты и грабли, концепция, карты работ) — в git вместе с кодом: «докс, касающийся Эларма, пусть тоже идут в гит».
- Последний коммит перед удалением — «Завершён. Темы подключены.»; после него в локальной папке `Alarm/` остаётся только `CLAUDE.md` (его владелец оставил для будущих проверок), сам устав в git не идёт.

## Почему
Правило 2026-08-29 держало документы вне git, потому что они жили рядом с кодом на этом компьютере. Теперь локальной копии нет — без git документы пропали бы насовсем.

## Цена
- Репозиторий публичный: документы видны всем. Личного в них нет — оно в хабе (`docs/ya/`).
- `builds/` (APK), `data/` (журнал с телефона), `capture/` и прочее вне git удалено без копии — по слову владельца.
