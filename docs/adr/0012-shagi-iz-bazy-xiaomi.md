# ADR-0012. Шаги берутся из системной базы Xiaomi; Alarm — телефонная часть хаба

- **Статус:** принят; «код телефона — весь здесь» снято ADR-0013 (2026-10-08) — сбор данных для хаба по-прежнему здесь
- **Дата:** 2026-09-13
- **Решение владельца:** сбор данных с телефона живёт в Alarm, а не в отдельном приложении; источник шагов — «только база Xiaomi»
- **Отход от:** P0 №11 («никакого чтения чужих данных»)
- **Копия:** `Sashboard/docs/adr/0019-shagi-iz-bazy-xiaomi.md` (сквозное решение — лежит в обоих проектах)

## Контекст

Нужен шагомер: телефон считает шаги постоянно, компьютер рисует график. Проверка по кабелю 2026-09-13: аппаратный `step_counter` постоянно не держит никто (неудерживаемый счётчик по документации Android вправе не считать), а системная служба `com.miui.server.stepcounter.StepCounterManagerService` держит `step_detect_wakeup` круглосуточно и складывает шаги в провайдер `com.miui.providers.steps` (`com.miui.rom`). Разрешение `miui.permission.READ_STEPS` — уровня `normal`, выдаётся при установке.

## Решение

1. **Своего счёта шагов нет**: ни датчика, ни таймеров, ни службы с уведомлением. Источник один — провайдер Xiaomi.
2. **Чтение — в момент передачи журнала** (`SyncReceiver.collectAndSend`), окном во всю историю базы (владелец, 2026-09-13); повторов нет — записанные корзины отсеиваются.
3. **В журнал идут минутные корзины** (владелец, вечер 2026-09-13; до этого были четвертьчасовые — они остались в журнале, компьютер отбрасывает крупный отрезок, перекрытый мелким) `steps.interval` (`fromMillis`, `toMillis`, `steps`): только закрытые (конец не позже 15 минут до чтения) и только ещё не записанные. Правило — `core/StepBuckets.kt`.
4. Статус источника — строка «Шаги (Xiaomi)» в разрешениях (P0 №8).

## Цена

- **Зависимость от прошивки Xiaomi**: обновление может закрыть провайдер или сменить схему, и шаги молча перестанут приходить. Запасного источника нет — выбор владельца.
- Провайдер требует два разрешения: `READ_STEPS` (при установке) и `ACTIVITY_RECOGNITION` (диалог по строке «Шаги (Xiaomi)»). Схема `_begin_time`, `_end_time`, `_steps` подтверждена на телефоне 2026-09-13. Оболочка adb провайдер не читает — сырые строки только через `StepsDumpReceiver`.
