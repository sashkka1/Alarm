# ADR-0001. Нативный Android на Kotlin и Compose вместо React Native

- **Статус:** принят
- **Дата решения:** 2026-08-12
- **Записан задним числом:** 2026-08-27 — решение действовало с первого дня, но файла у него не было; текст восстановлен по уставу и по коду
- **Решение владельца:** да, 2026-08-12

## Контекст

Устав этого проекта — переработка устава проекта Amenova, написанного под **React Native + Expo**. Оттуда же тянулась привычка к стеку: два языка, JS-рантайм, единая кодовая база под iOS и Android.

Приложение при этом делает ровно одно: **в момент чужого будильника мгновенно поднимает свой экран поверх всего и не даёт с него уйти.** Всё остальное — настройки вокруг этого момента.

## Решение

**Только Android, только Kotlin, интерфейс на Jetpack Compose + Material 3.** JDK 17. Сборка Gradle KTS, установка APK по кабелю: ни Google Play, ни App Store, ни аккаунтов, ни сервера.

## Почему

1. **Системная часть всё равно нативная.** Слушатель уведомлений, точные будильники, оверлей поверх всего, Lock Task, Device Owner, приёмник загрузки, сторож в отдельном процессе — всё это Android API. В RN каждый из них потребовал бы своего моста, то есть тот же нативный код плюс прослойка над ним.
2. **JS-рантайм добавляет задержку старта ровно в тот момент, когда её нельзя добавлять.** Экран тревоги обязан появиться мгновенно; холодный старт с инициализацией рантайма — это секунды, которых нет.
3. **Второй платформы не будет.** Приложение живёт на одном телефоне владельца (Xiaomi Redmi Note, HyperOS 3, Android 16). Кроссплатформенность здесь оплачивается, но не используется.
4. **Меньше слоёв — меньше мест, где будильник может промолчать** (P0 №7).

## Последствия

- Раскладка модулей `:core` · `:platform` · `:ui` · `:app`; `:core` без Android SDK и под тестами (P0 №1, №2).
- Из устава Amenova выброшено всё про магазины, аккаунты, монетизацию, аналитику и вторую платформу.
- Обратной дороги к общей кодовой базе с iOS нет — но она и не планировалась.

## Что отменит это решение

Появление второй платформы. Пока телефон один, вопрос не стоит.
